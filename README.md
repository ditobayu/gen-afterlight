# AFTERLIGHT — The Last Sunset, Bottled.

A fictional fragrance house presented as six cinematic scenes. Built with React, TypeScript, Vite, GSAP ScrollTrigger, React Three Fiber, Three.js, and custom GLSL.

## Run

```sh
npm install
npm run dev
```

`npm run build` checks TypeScript and creates the production site in `dist/`. `npm run preview` serves that build.

## Experience

- Sculpted smoked-glass bottle, internally modeled amber, procedural reflection studio, engraved canvas texture, floating parallax, and inertial drag inspection.
- Living solar sphere with animated domain-warped noise, dimensional deformation, corona, particle convergence, and scroll-driven collapse into the bottle.
- Six scenes with pinned choreography, typographic masks, art-directed image reveals, fullscreen chapter navigation, magnetic CTA, custom cursor, and optional synthesized ambient sound.
- Mobile compositions, keyboard navigation, a native accessible artifact dialog, and reduced-motion adaptation.

## Assets

Five bespoke artworks were generated with the built-in image generation tool. Final WebP assets are in `public/images/`. Prompts and preserved PNG originals are in `design-assets/`. Font files are served locally in `public/fonts/` (Bodoni Moda and DM Sans, distributed under the SIL Open Font License via Google Fonts).

AFTERLIGHT is fictional. No purchase, contact transmission, or real social account is implied by the exhibition. Contact and Instagram controls display the concept-house note.
